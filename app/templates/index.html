Fluxo recomendado

  1. Configure as credenciais necessárias em Configurações > API Keys.
  2. Informe o alvo e escolha o modo de execução em Execução.
  3. Acompanhe logs em tempo real utilizando o Mode Console.
  4. Revise os resultados estruturados e faça o download do relatório Markdown em Resultados.

    Mode Console

    Interface emulando um terminal Linux. Os comandos são os mesmos do utilitário CLI, permitindo reproduzir execuções de módulos, bundles ou do pipeline completo.

    Comandos úteis

    • list modules — Lista módulos registrados.
    • run module shodan --target exemplo.com — Executa um módulo individual.
    • run bundle discovery --target exemplo.com — Executa uma categoria completa.
    • run all --target exemplo.com — Executa todos os módulos disponíveis.

    Utilize help para ver todos os comandos suportados pelo console.
